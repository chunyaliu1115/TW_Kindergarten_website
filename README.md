# 仁仁森林幼兒園 (Ren Ren Forest Kindergarten) 官方網站

這是 [仁仁森林幼兒園](https://www.znzn.com.tw) 的官方網站專案原始碼。本園位於台南市安南區，致力於提供孩子一個充滿自然生態與美學啟發的學習環境。

**官方網站 (Live Website):** [www.znzn.com.tw](https://www.znzn.com.tw)

## 專案核心內容 (Website Features)

*   **園所理念與環境：** 呈現幼兒園的教育核心價值、自然校園生態與專業師資團隊。
*   **特色活動與美學展演：** 數位化紀錄園內舉辦的各項精采活動與美感教育（如：「LouLou Art 小小羅浮宮」兒童藝術展）。
*   **家長資訊與園務公告：** 提供完整的招生資訊、校園最新公告與聯絡表單，方便家長即時獲取資訊。

## 網頁前端技術 (Tech Stack)

*   React
*   TypeScript
*   Tailwind CSS

## 本機開發環境 (Local Development)

如需在本地端運行此網站原始碼，請確保環境已安裝 Node.js 與 npm，並於終端機執行以下指令：

```sh
git clone [https://github.com/您的GitHub帳號/znzn-website.git](https://github.com/您的GitHub帳號/znzn-website.git)
cd znzn-website
npm install
npm run dev
